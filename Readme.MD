# Trust Elara Clone (MERN Stack)

This repository contains the full-stack MERN (MongoDB, Express, React, Node.js) implementation of the **Trust Elara** web application clone, developed during an internship. 

The project includes a complete backend API along with two separate frontend applications: one for **Customers** and another for **Admin** management.

---

## 🚀 Features

* **Customer Portal**: Browse products/services, view details, and interact with the main platform interface.
* **Admin Portal**: Management interface for handling platform data, content, and system administration.
* **Backend API**: RESTful API built with Express and Node.js connected to MongoDB for persistent data storage.
* **CORS Enabled**: Configured cross-origin resource sharing to connect frontend apps seamlessly to the backend.

---

## 🛠️ Tech Stack

* **Frontend**: React.js, JavaScript, CSS3, HTML5
* **Backend**: Node.js, Express.js
* **Database**: MongoDB
* **Tools & Utilities**: CORS, REST APIs, Git
